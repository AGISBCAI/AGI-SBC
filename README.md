AGI-SBC

Artificial General Intelligence – Smart Business Companion

AGI-SBC is a project focused on building an Android application and a Web App with a secure, controlled user-management system.

Project Goals

- Build an Android application (APK).
- Build a compatible Web App.
- Maintain a simple and accessible user interface.
- Establish secure authentication and user management.
- Keep the project open to future improvements.

User Access and Security

- Only the permanent "OWNER_ADMIN" can create and manage regular user accounts.
- Public registration is disabled.
- Regular users cannot promote themselves to administrator.
- Additional owner accounts and ownership transfers are not permitted.

Technology Foundation

- Expo
- React Native
- TypeScript
- Expo Router
- GitHub Actions
